# Fencing Protocols

[RU]

Офлайн-приложение для ведения протоколов по фехтованию. Работает без интернета, все данные хранятся на устройстве.

**Возможности**

- Шпага, рапира, сабля; несколько пулек-дорожек в одном старте и общий рейтинг.
- Олимпийка сеткой-деревом: посев по рейтингу, свободные проходы, бой за 3-е место.
- Окно боя: счёт, таймер, приоритет, карточки и снятие бойца по правилам FIE.
- Экспорт в PDF, CSV и JSON, печать; 5 языков.

**Как поставить на iPhone**

1. Открыть адрес приложения в Safari.
2. «Поделиться» → «На экран „Домой“» → «Добавить».
3. Один раз запустить с иконки при интернете — дальше работает офлайн.

[EN]

Offline app for fencing protocols. Works without internet, all data is stored on the device.

**Features**

- Épée, foil, sabre; several pools (pistes) in one event with a combined ranking.
- Direct elimination bracket: seeding by ranking, byes, bout for 3rd place.
- Bout screen: score, timer, priority, cards and withdrawals following FIE rules.
- Export to PDF, CSV and JSON, printing; 5 languages.

**Install on iPhone**

1. Open the app's address in Safari.
2. Share → Add to Home Screen → Add.
3. Launch it from the icon once while online — after that it works offline.

## dev

```bash
npm install
npm run dev
```
